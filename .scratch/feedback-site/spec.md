# Spec: 가람중학교 「전기와 자기」 수업 피드백 사이트

## 1. 목표

학생이 오늘 수업에서 잘 이해한 내용과 아직 어려운 내용을 자기 말로 작성해 제출하고, 선생님이 제출 내용을 확인한 뒤 짧은 피드백을 공개할 수 있는 사이트를 만든다.

## 2. 범위와 구현 제약

- 모든 화면은 `index.html` 하나에 만든다.
- 학생 화면과 선생님 화면은 페이지를 새로 열지 않고 `index.html` 안에서 전환해 보여 준다.
- 데이터는 브라우저의 `localStorage`에만 저장한다.
- 서버, 데이터베이스, 회원 계정은 사용하지 않는다.
- 자동화된 테스트 도구는 사용하지 않는다. 브라우저에서 직접 화면과 동작을 확인한다.
- PRD에 정의된 학생 제출, 선생님 확인, 피드백 공개 흐름만 구현한다.

## 3. 사용자와 진입

### 학생

1. 학생은 이름을 입력한다.
2. 이름을 입력하면 학생 화면으로 이동한다.
3. 학생 화면에서 오늘의 수업 정보, 답변 입력란, 공개된 피드백을 확인한다.

### 선생님

- 선생님 화면은 관리자 비밀번호를 입력해야 열린다.
- 실습용 관리자 비밀번호는 `teacher-demo`로 한다.
- 관리자 비밀번호를 입력하기 전에는 학생 글과 선생님만 보는 내용이 화면에 보이지 않는다.
- 선생님 화면은 학생 화면과 전환할 수 있다.

## 4. 화면 요구사항

### 4.1 학생 이름 입력 화면

- 이름 입력란을 보여 준다.
- 이름을 입력하지 않으면 학생 화면으로 이동할 수 없다.
- 이름을 입력하면 해당 이름으로 학생 화면을 연다.

### 4.2 학생 화면

다음 내용을 보여 준다.

- 오늘의 수업 제목
- 「전기와 자기」 단원의 짧은 학습 안내
- `오늘 가장 잘 이해한 내용은 무엇인가요?` 질문과 답변 입력란
- `아직 어려운 내용은 무엇인가요?` 질문과 답변 입력란
- 답변 제출 버튼
- 선생님이 공개한 피드백

동작은 다음과 같다.

- 두 질문에 대한 답변을 작성한 뒤 제출한다.
- 제출한 답변은 수업 날짜와 학생 이름을 포함해 저장한다.
- 선생님이 공개한 피드백만 학생에게 보여 준다.
- 선생님이 아직 공개하지 않은 피드백은 보여 주지 않는다.
- 제출 후 답변은 수정할 수 없다. (AI 제안)
- 답변 글자 수에는 별도 제한을 두지 않는다. (AI 제안)

### 4.3 선생님 제출 현황 화면

다음 내용을 보여 준다.

- 현재 수업에 대한 학생들의 제출 현황
- 학생별 답변 목록
- 각 제출 항목의 학생 이름과 제출 상태

- 학생의 답변 항목을 선택하면 해당 학생의 답변 화면을 연다.

### 4.4 선생님 답변 확인 및 피드백 화면

- 학생 이름을 보여 준다.
- 학생이 작성한 `가장 잘 이해한 내용`을 보여 준다.
- 학생이 작성한 `아직 어려운 내용`을 보여 준다.
- 짧은 피드백 입력란을 보여 준다.
- 피드백 공개 버튼을 제공한다.

동작은 다음과 같다.

- 선생님은 학생의 답변을 읽고 피드백을 작성한다.
- 공개 버튼을 누른 피드백을 해당 학생에게 공개한다.
- 공개 전 피드백은 학생 화면에서 보이지 않는다.
- 공개된 피드백은 학생이 다시 학생 화면에 들어왔을 때 확인할 수 있다.

## 5. 수업 범위

- 한 번에 하나의 학급과 하나의 수업만 다룬다. (AI 제안)
- 수업 제목과 학습 안내는 이번 실습에서 정해 둔 내용으로 표시한다.
- 여러 학급이나 여러 수업을 생성·선택·관리하는 기능은 만들지 않는다. (AI 제안)
- 학생의 답변과 피드백은 수업 날짜별로 구분해 저장한다.

## 6. 데이터 저장

`localStorage`에 다음 정보를 저장한다.

### 수업 정보

- 수업 날짜
- 수업 제목
- 학습 안내

### 학생 답변

- 수업 날짜
- 학생 이름
- 가장 잘 이해한 내용
- 아직 어려운 내용
- 제출 여부
- 피드백 내용
- 피드백 공개 여부

저장 키 이름과 JSON 구조는 구현 시 자유롭게 정하되, 새로고침해도 저장된 답변과 공개된 피드백이 유지되어야 한다.

## 7. 시각적·반응형 범위

- 학생과 선생님이 내용을 읽고 입력할 수 있는 단순한 기본 레이아웃으로 만든다.
- 별도 브랜드 디자인이나 복잡한 시각 효과는 구현하지 않는다. (AI 제안)
- 데스크톱 브라우저에서 확인 가능한 범위로 만들고, 좁은 화면에서는 내용이 잘리지 않도록 기본적인 반응형 배치만 적용한다. (AI 제안)

## 8. 만들지 않는 기능

- 준비된 문장을 버튼으로 골라 피드백하는 기능
- 선생님이 공개하기 전에 학생에게 피드백을 보여 주는 기능
- 최근 글만 남기고 이전 답변을 지우는 기능
- 학생이 학급 코드로 들어가는 기능
- 학생별 아이디와 비밀번호로 로그인하는 기능
- 선생님 계정, 관리자 비밀번호 변경, 권한 관리 기능
- 여러 학급이나 여러 수업을 관리하는 기능
- 서버 또는 데이터베이스 저장
- 자동화된 테스트

## 9. 완료 조건

- 학생이 이름을 입력하고 오늘 수업 제목과 학습 안내를 볼 수 있다.
- 학생이 두 질문에 자기 말로 답하고 제출할 수 있다.
- 제출 내용이 `localStorage`에 저장되고 새로고침 뒤에도 유지된다.
- 선생님 화면에서 제출 현황과 학생별 답변 목록을 볼 수 있다.
- 선생님이 학생 답변을 읽고 피드백을 작성해 공개할 수 있다.
- 학생 화면에서 공개된 피드백만 확인할 수 있다.
- 학생 화면과 선생님 화면이 `index.html` 안에서 전환된다.
