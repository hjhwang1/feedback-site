# PRD: 가람중학교 「전기와 자기」 수업 이해 기록 사이트

## 1. 제품 개요

수업이 끝난 뒤 학생이 오늘 이해한 내용과 어려운 내용을 자기 말로 작성해 제출하고, 선생님이 학생의 글을 읽은 뒤 짧은 글로 피드백을 남기는 웹사이트다.

## 2. 대상

- 가상의 가람중학교 2학년 학생
- 가상의 가람중학교 과학 선생님
- 수업 단원: 과학 「전기와 자기」

## 3. 핵심 사용자 흐름

1. 학생이 이름을 직접 입력해 사이트에 들어온다.
2. 학생은 오늘의 수업 제목과 짧은 학습 안내를 본다.
3. 학생은 다음 두 질문에 답한다.
   - 오늘 가장 잘 이해한 내용은 무엇인가요?
   - 아직 어려운 내용은 무엇인가요?
4. 학생이 답변을 제출한다.
5. 답변은 수업 날짜별로 저장된다.
6. 선생님은 학생들의 제출 현황과 답변 목록을 본다.
7. 선생님은 학생 이름과 제출한 글을 확인한다.
8. 선생님은 짧은 글로 피드백을 작성하고 공개한다.
9. 학생은 선생님이 공개한 피드백을 확인한다.

## 4. 학생 화면 요구사항

### 4.1 첫 화면

학생이 사이트에 들어오면 다음을 보여 준다.

- 오늘의 수업 제목
- 「전기와 자기」 단원의 짧은 학습 안내

### 4.2 글쓰기 화면

다음 질문을 보여 주고 학생이 자기 말로 답할 수 있게 한다.

- 오늘 가장 잘 이해한 내용은 무엇인가요?
- 아직 어려운 내용은 무엇인가요?

### 4.3 피드백 확인

- 선생님이 공개한 피드백을 학생이 확인할 수 있어야 한다.

## 5. 선생님 화면 요구사항

### 5.1 첫 화면

선생님이 사이트에 들어오면 다음을 보여 준다.

- 학생들의 제출 현황
- 학생들의 답변 목록

### 5.2 학생 답변 화면

선생님이 학생 한 명의 답변을 선택하면 다음을 보여 준다.

- 학생 이름
- 학생이 제출한 글

### 5.3 피드백

- 선생님은 학생의 글을 읽고 짧은 글로 피드백을 작성할 수 있다.
- 선생님은 작성한 피드백을 공개할 수 있다.

## 6. 수업 질문과 안내 관리

- 선생님이 사용하는 질문은 수정할 수 있어야 한다.
- 학생에게 보여 주는 수업 안내도 수정할 수 있어야 한다.

## 7. 저장 및 기록

- 학생의 답변은 수업 날짜별로 저장한다.
- 선생님의 피드백도 학생 답변과 함께 저장한다.
- 공개된 피드백은 학생이 다시 확인할 수 있다.

## 8. 확정하지 않은 내용

다음 내용은 아직 정하지 않는다.

- 학생 답변의 글자 수 제한
- 제출 후 답변 수정 가능 여부
- 여러 학급 또는 여러 수업을 관리하는 방법
- 선생님 로그인 방법
- 사이트의 시각적 디자인
- 모바일 지원 범위
